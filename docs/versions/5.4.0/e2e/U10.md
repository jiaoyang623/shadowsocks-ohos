### TC-U10-01 Scan a valid SIP002 QR code and add its profile

- Preconditions:
  - The camera permission has not been granted yet
  - The current profile uses route bypass-lan
  - A QR code encodes ss://YWVzLTI1Ni1nY206cGFzcw@example.com:8388#Test
- Steps:
  1. Open Add Profile and tap Scan QR code
  2. Allow the camera prompt and point the camera at the QR code
- Expected:
  1. The scanner opens and the system camera permission prompt appears
  2. The camera preview appears, one profile named Test is created with host example.com, port 8388 and method aes-256-gcm, and it copies the current profile route, IPv6, metered, proxy-app and UDP-DNS settings. The scanner closes and the profile list shows the new profile
- Control path: `C-U10-001 > C-U10-005`
- HarmonyOS parity: implemented
- Android source: `mobile/src/main/java/com/github/shadowsocks/ScannerActivity.kt:139`

### TC-U10-21 A scan copies the feature settings of the current profile

- Preconditions:
  - The camera permission is granted
  - The current profile uses route bypass-lan and IPv6 on
  - The current profile turns metered, per-app proxy and UDP DNS on
  - A QR code encodes one valid ss:// URL
- Steps:
  1. Open the scanner and point the camera at the code
  2. Wait for the scanner to close
  3. Open the new profile and read its feature settings
