### TC-U01-18 Ctrl+G toggles the service

- Preconditions:
  - The main screen has focus and a hardware keyboard is attached
  - At least one profile is selected
  - The service is Stopped
  - The VPN consent is already granted, so the start contract opens no dialog
- Steps:
  1. Press Ctrl+G while the state is Stopped
  2. Press Ctrl+G again while the state is Connecting. Wait for Stopped, start the service again, wait for Connected, then press Ctrl+G.
  3. While the state is Stopping, press Ctrl+G again
  4. Wait for Stopped, force-stop the app process, launch the app and press Ctrl+G before the binding reports the service state, so the UI shows Idle
- Expected:
  1. The first press launches the start contract and the service reports Connecting
  2. Each of those presses broadcasts CLOSE and the service reports Stopping, because state.canStop is true for Connecting and Connected
  3. The press while Stopping launches a start that the service ignores because its Data.state is Stopping. The teardown still reaches Stopped.
  4. The press while the UI shows Idle starts the service although the button is disabled, because Data.state is Stopped. Idle is a UI-only state.
  5. The button and stats bar follow the states that the service reports, as in F-U01-01 and F-U01-02
- Control path: `C-U01-001 > C-U01-025`
- HarmonyOS parity: implemented
- Android source: `mobile/src/main/java/com/github/shadowsocks/MainActivity.kt:227`
