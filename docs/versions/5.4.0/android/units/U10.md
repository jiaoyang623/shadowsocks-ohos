## Flows

### F-U10-01 Scan a QR code and add its profiles

1. **start**: start: the user opens Add Profile and taps Scan QR code. Next: the scanner starts and requests the camera permission.
2. **step**: the scanner starts and requests the camera permission. Next: decision: is the camera permission granted?
3. **decision**: decision: is the camera permission granted? Decision exit: yes: the camera provider binds a preview and the analyzer.
4. **step**: yes: the camera provider binds a preview and the analyzer. Next: the analyzer decodes QR codes from camera frames.
5. **step**: the analyzer decodes QR codes from camera frames. Next: decision: does the decoded text hold at least one ss:// URL?
6. **decision**: decision: does the decoded text hold at least one ss:// URL? Decision exit: yes: each URL becomes a profile and the scanner clears the analyzer.
7. **step**: yes: each URL becomes a profile and the scanner clears the analyzer. Next: end: the scanner navigates up and the profile list shows the new profiles.
8. **end**: end: the scanner navigates up and the profile list shows the new profiles.
9. **step**: no: no profile is created and the scanner keeps analyzing. Next: the analyzer decodes QR codes from camera frames.
10. **end (exception exit)**: no: the permission toast shows and the image picker opens (F-U10-03).
11. **end (exception exit)**: no: the camera bind throws IllegalArgumentException and the image picker opens (F-U10-03).

Exception exits:
- The camera permission is denied: the toast Camera permission is required for scanning QR code. shows and the image picker opens.
- bindToLifecycle throws IllegalArgumentException: the image picker opens without a toast.
- A decoded value is not a valid ss:// URL: it is skipped and scanning continues.
- The user taps up before any code is decoded: the scanner closes with no profile.

### F-U10-02 Import profiles from images with the scanner menu

1. **start**: start: the user taps Import from file… in the scanner toolbar. Next: the image picker opens for image/* with multiple selection.
2. **step**: the image picker opens for image/* with multiple selection. Next: decision: did the user select at least one image?
3. **decision**: decision: did the user select at least one image? Decision exit: yes: the scanner navigates up and then decodes each image.
4. **step**: yes: the scanner navigates up and then decodes each image. Next: decision: did any image yield at least one profile?
5. **decision**: decision: did any image yield at least one profile? Decision exit: yes: the Successfully import! toast shows.
6. **end**: yes: the Successfully import! toast shows.
7. **end**: no: the Failed to import. toast shows.
8. **end**: no: the picker returns nothing and the scanner stays open.
9. **end (exception exit)**: no: an image read throws and a long toast shows the readable message.

Exception exits:
- The picker is cancelled: the scanner stays on the preview.
- An image cannot be read: after every image is tried, the exception message shows in a long toast.
- The scanner closes before the images are read, so the result toast appears on the profile list.

### F-U10-03 Fall back to the image picker when the camera is unavailable

1. **start**: start: the scanner starts and the camera permission is denied. Next: the permission toast shows.
2. **step**: the permission toast shows. Next: the fallback picker opens for image/* and closes the scanner when it returns empty.
3. **step**: the fallback picker opens for image/* and closes the scanner when it returns empty. Next: decision: did the user select at least one image?
4. **decision**: decision: did the user select at least one image? Decision exit: yes: the import runs as in F-U10-02.
5. **end**: yes: the import runs as in F-U10-02.
6. **end**: no: the scanner closes without a toast.
7. **end (exception exit)**: no: the camera bind failed, so the picker opens without the permission toast.

Exception exits:
- The camera binds but throws IllegalArgumentException: the picker opens without a toast.
- The user cancels the fallback picker: the scanner closes and no profile changes.

### F-U10-04 Read About and follow a link

1. **start**: start: the user opens the drawer and taps About. Next: About replaces the content area and the drawer closes.
2. **step**: About replaces the content area and the drawer closes. Next: the toolbar title becomes Shadowsocks plus the version and about.html is rendered.
3. **step**: the toolbar title becomes Shadowsocks plus the version and about.html is rendered. Next: decision: does the tapped link start with #?
4. **decision**: decision: does the tapped link start with #? Decision exit: yes: the Google Play OSS licences screen opens.
5. **end**: yes: the Google Play OSS licences screen opens.
6. **decision**: no: decision: does the tapped link start with mailto:? Decision exit: yes: an email chooser titled Send email opens.
7. **end**: yes: an email chooser titled Send email opens.
8. **step**: no: the link opens in a Custom Tab. Next: decision: does an activity handle the URL?
9. **decision**: decision: does an activity handle the URL? Decision exit: yes: the browser shows the page.
10. **end**: yes: the browser shows the page.
11. **end (exception exit)**: no: a snackbar shows the raw URL.

Exception exits:
- No activity handles the URL: a snackbar shows the URL instead of opening a browser.
- The About body text is empty: the text view hides itself.

### F-U10-05 Open the scanner from the launcher shortcut

1. **start**: start: the user long-presses the app icon and taps Scan QR code. Next: ScannerActivity starts as its own task root.
2. **step**: ScannerActivity starts as its own task root. Next: the scanner reports the scan shortcut as used on API 25 and later.
3. **step**: the scanner reports the scan shortcut as used on API 25 and later. Next: the scanner continues as F-U10-01.
4. **step**: the scanner continues as F-U10-01. Next: decision: is the scanner the task root?
5. **decision**: decision: is the scanner the task root? Decision exit: yes: the up action recreates the parent task.
6. **end**: yes: the up action recreates the parent task.
7. **end**: no: the up action just finishes the scanner.

Exception exits:
- The camera is denied or fails to bind: the image picker fallback runs.
- The shortcut is used on API 24 or earlier: the report call is skipped.
