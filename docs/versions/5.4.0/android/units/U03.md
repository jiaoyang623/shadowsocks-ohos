## Flows

### F-U03-01 Open a profile in the editor

1. **start**: The user taps the edit control on a profile row.
2. **step**: ProfilesFragment.startConfig calls profile.serialize and starts the activity with the profile id.
3. **decision**: Does the intent carry a profile id other than -1 and other than the stored editing id? Decision exit: No → system: the form shows the draft values in three categories. Yes → end: the activity finishes before drawing the form.
4. **step**: The form shows the draft values in three categories.
5. **step**: IPv6 Route and Apps VPN mode are enabled only in VPN mode, and an Active subscription disables the transport rows.
