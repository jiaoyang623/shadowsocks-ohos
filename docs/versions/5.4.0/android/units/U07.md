## Flows

### F-U07-01 Open Apps VPN mode and select apps

1. **start**: User: taps the Apps VPN mode switch in the profile editor. Next: Decision: the service mode is VPN.
2. **decision**: Decision: the service mode is VPN. Decision exit: Yes: AppManager opens / No: the switch is disabled and the flow ends.
3. **step**: Yes: AppManager opens. Next: Decision: Apps VPN mode was off.
4. **end**: No: the switch is disabled and the flow ends.
5. **decision**: Decision: Apps VPN mode was off. Decision exit: Yes: the screen turns it on and sets the shared dirty flag / No: the screen keeps the stored values.
6. **step**: Yes: the screen turns it on and sets the shared dirty flag. Next: System: scans installed packages.
7. **step**: No: the screen keeps the stored values. Next: System: scans installed packages.
8. **step**: System: scans installed packages. Next: System: shows the app list.
9. **step**: System: shows the app list. Next: User: taps an app row.
10. **step**: User: taps an app row. Next: Decision: the app was selected.
11. **decision**: Decision: the app was selected. Decision exit: Yes: the switch turns off and the package leaves the list / No: the switch turns on and the package joins the list.
12. **step**: Yes: the switch turns off and the package leaves the list. Next: User: leaves the screen.
13. **step**: No: the switch turns on and the package joins the list. Next: User: leaves the screen.
14. **end**: User: leaves the screen.

Exception exits:
- The entry switch is disabled in proxy and transproxy service modes
- A cancelled reload leaves the spinner in place until the next load finishes
- The editor switch sets Apps VPN mode before the screen starts, so the off branch is not reachable from the editor

### F-U07-02 Change the per-app mode

1. **start**: User: taps one choice in the Mode group. Next: Decision: the choice is Off.
2. **decision**: Decision: the choice is Off. Decision exit: Yes: the screen closes with Apps VPN mode off / No: the screen stays open.
3. **end**: Yes: the screen closes with Apps VPN mode off.
4. **step**: No: the screen stays open. Next: Decision: the choice is Bypass.
5. **decision**: Decision: the choice is Bypass. Decision exit: Yes: the bypass flag becomes true / No: the bypass flag becomes false.
6. **step**: Yes: the bypass flag becomes true. Next: System: keeps the selected app list.
7. **step**: No: the bypass flag becomes false. Next: System: keeps the selected app list.
8. **step**: System: keeps the selected app list. Next: System: sets the shared dirty flag.
9. **end**: System: sets the shared dirty flag.

Exception exits:
- None.

### F-U07-03 Filter the app list

1. **start**: User: focuses the search field. Next: User: types a query.
2. **step**: User: types a query. Next: Decision: a row matches the query.
3. **decision**: Decision: a row matches the query. Decision exit: Yes: the row stays / No: the row is hidden.
4. **step**: Yes: the row stays. Next: User: clears the query.
5. **step**: No: the row is hidden. Next: User: clears the query.
6. **end**: User: clears the query.

Exception exits:
- The keyboard search action does nothing, because onQueryTextSubmit returns false

### F-U07-04 Apply per-app settings to every profile

1. **start**: User: opens the overflow menu. Next: User: taps Apply Settings to All Profiles.
2. **step**: User: taps Apply Settings to All Profiles. Next: Decision: the profile list is readable.
3. **decision**: Decision: the profile list is readable. Decision exit: Yes: every profile receives the list and bypass flag / No: a failure snackbar appears.
4. **step**: Yes: every profile receives the list and bypass flag. Next: Decision: every profile update matches one row.
5. **decision**: Decision: every profile update matches one row. Decision exit: Yes: updates the direct-boot copy if direct boot is enabled / No: the write throws after the earlier profiles were stored.
6. **step**: Yes: updates the direct-boot copy if direct boot is enabled. Next: System: shows Apply Settings to All Profiles.
7. **end**: System: shows Apply Settings to All Profiles.
8. **step (exception exit)**: No: the write throws after the earlier profiles were stored. Next: System: shows no snackbar.
9. **end (exception exit)**: System: shows no snackbar.
10. **step (exception exit)**: No: a failure snackbar appears. Next: System: shows Failed to export.
11. **end (exception exit)**: System: shows Failed to export.

Exception exits:
- The failure path reuses the export error text
- A profile update checks the row count, so a failed update throws after the earlier profiles were written
- A thrown update leaves the profile list partially written and shows no snackbar

### F-U07-05 Export per-app settings to the clipboard

1. **start**: User: taps Export to Clipboard. Next: App: writes the bypass flag, a newline, and the package list.
2. **step**: App: writes the bypass flag, a newline, and the package list. Next: Decision: the clipboard write succeeds.
3. **decision**: Decision: the clipboard write succeeds. Decision exit: Yes: shows Successfully export! / No: shows Failed to export.
4. **end**: Yes: shows Successfully export!
5. **end (exception exit)**: No: shows Failed to export.

Exception exits:
- A RuntimeException from the clipboard service becomes the failure snackbar

### F-U07-06 Import per-app settings from the clipboard

1. **start**: User: taps Import from Clipboard. Next: App: reads the first clipboard item.
2. **step**: App: reads the first clipboard item. Next: Decision: the text is null or empty.
3. **decision**: Decision: the text is null or empty. Decision exit: Yes: shows Failed to import. / No: splits the text.
4. **end (exception exit)**: Yes: shows Failed to import.
5. **step**: No: splits the text. Next: Decision: the text contains a newline.
6. **decision**: Decision: the text contains a newline. Decision exit: Yes: the first line is the flag and the rest are packages / No: the whole text is the flag and the list becomes empty.
7. **step**: Yes: the first line is the flag and the rest are packages. Next: App: checks Bypass or On.
8. **step**: No: the whole text is the flag and the list becomes empty. Next: App: checks Bypass or On.
9. **step**: App: checks Bypass or On. Next: App: stores the package list and sets the shared dirty flag.
10. **step**: App: stores the package list and sets the shared dirty flag. Next: System: shows Successfully import!
11. **end**: System: shows Successfully import!

Exception exits:
- Android 10 and later return no clipboard text when the app lacks window focus
- A first line other than true reads as false and selects On

### F-U07-07 Start the VPN with per-app rules

1. **start**: User: connects the profile. Next: System: requests VPN consent.
2. **step**: System: requests VPN consent. Next: Decision: Apps VPN mode is on.
3. **decision**: Decision: Apps VPN mode is on. Decision exit: Yes: reads the package list / No: excludes only the client package.
4. **step**: No: excludes only the client package. Next: System: establishes the tunnel.
5. **step**: Yes: reads the package list. Next: Decision: bypass mode is on.
6. **decision**: Decision: bypass mode is on. Decision exit: Yes: disallows each package / No: allows each package.
7. **step**: Yes: disallows each package. Next: Decision: the package is the client package.
8. **step**: No: allows each package. Next: Decision: the package is the client package.
9. **decision**: Decision: the package is the client package. Decision exit: Yes: skips the client package / No: checks whether the package is installed.
10. **step**: Yes: skips the client package. Next: App: keeps the client package outside the tunnel.
11. **step**: No: checks whether the package is installed. Next: Decision: the package is installed.
12. **decision**: Decision: the package is installed. Decision exit: Yes: adds the package to the VPN builder / No: skips the package.
13. **step**: Yes: adds the package to the VPN builder. Next: App: keeps the client package outside the tunnel.
14. **step**: No: skips the package. Next: App: keeps the client package outside the tunnel.
15. **step**: App: keeps the client package outside the tunnel. Next: System: establishes the tunnel.
16. **end**: System: establishes the tunnel.

Exception exits:
- An uninstalled package raises NameNotFoundException and is logged
- The package list and the bypass flag are read once at VPN start, so edits made while the VPN runs reach the tunnel only after a reconnect
- establish returns null and the start fails with the reboot message

### F-U07-08 Turn Apps VPN mode off and leave the screen

1. **start**: User: taps Off. Next: App: turns Apps VPN mode off and sets the shared dirty flag.
2. **step**: App: turns Apps VPN mode off and sets the shared dirty flag. Next: App: finishes the screen.
3. **step**: App: finishes the screen. Next: Decision: the user saves the profile.
4. **decision**: Decision: the user saves the profile. Decision exit: Yes: the profile stores the off state / No: the profile keeps its old state.
5. **end**: Yes: the profile stores the off state.
6. **end**: No: the profile keeps its old state.

Exception exits:
