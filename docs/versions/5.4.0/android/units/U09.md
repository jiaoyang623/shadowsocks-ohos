## Flows

### F-U09-01 Open the global settings screen

- **start** User: opens the navigation drawer
  - **step** User: taps the Settings entry
    - **decision** Decision: the Settings entry was already checked
      - **decision exit** → **end** Yes: the drawer closes and the screen stays
      - **decision exit** → **step** No: the settings screen replaces the profile list
        - **step** System: binds the public preference store and seeds defaults
          - **decision** Decision: the service state is Stopped
            - **decision exit** → **step** Yes: the service mode and port rows are enabled
              - **end** System: shows the first two rows and the Advanced button
            - **decision exit** → **step** No: the service mode and port rows are disabled
              - **end** System: shows the first two rows and the Advanced button

Exception exits:
- The service bind fails, so the state stays Idle and every service row is disabled.
- The Settings entry is already checked, so the drawer closes and the screen does not change.

### F-U09-02 Expand the collapsed settings rows

- **start** User: taps the Advanced button
  - **step** System: expands the preference group
    - **decision** Decision: the service state is Stopped
      - **decision exit** → **step** Yes: the port rows appear enabled
        - **end** System: shows all six rows and removes the Advanced button
      - **decision exit** → **step** No: the port rows appear disabled
        - **end** System: shows all six rows and removes the Advanced button

Exception exits:
- The user leaves the screen after expanding, so the next visit starts collapsed again.

### F-U09-03 Change the service mode

- **start** User: taps the Service mode row
  - **decision** Decision: the row is enabled **(exception exit)**
    - **decision exit** → **step** Yes: the service mode popup opens
      - **step** User: taps an entry in the popup
        - **decision** Decision: the tapped entry differs from the stored value
          - **decision exit** → **step** Yes: the new value is stored
            - **decision** Decision: the new mode is transproxy
              - **decision exit** → **step** Yes: the Transproxy port row becomes enabled
                - **end** System: the main screen rebinds the service connection
              - **decision exit** → **step** No: the Transproxy port row becomes disabled
                - **end** System: the main screen rebinds the service connection
          - **decision exit** → **end** No: the popup closes without a write
    - **decision exit** → **end** No: nothing happens **(exception exit)**

Exception exits:
- The service is not Stopped, so the row is disabled and the flow cannot start.
- The stored mode is an unknown string, so the service class lookup throws when the main screen binds.

### F-U09-04 Edit a local port value

- **start** User: taps an enabled port row
  - **step** System: opens the port dialog with the stored text
    - **decision** Decision: the user taps OK
      - **decision exit** → **step** Yes: the typed text is stored
        - **decision** Decision: the text is empty
          - **decision exit** → **step** Yes: the row shows Not set
            - **decision** Decision: the text is inside 1025 to 65535
              - **decision exit** → **end** Yes: the core uses the stored text as the port
              - **decision exit** → **end** No: the core uses the default port instead
          - **decision exit** → **step** No: the row shows the typed text
            - **decision** Decision: the text is inside 1025 to 65535
              - **decision exit** → **end** Yes: the core uses the stored text as the port
