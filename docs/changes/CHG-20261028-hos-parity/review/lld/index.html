决策卡

每个决策选一个选项。要改就选「这个决策要改」，并写原因。

决策 1 · Does one shared field set serve every unit that changes a profile?

原因：Five units change the profile record and the settings record.

决策 2 · Should the model land before the pages?

原因：Pages call model functions. A page written against a guessed signature fails at build time.

决策 3 · Is one owner per shared file enough to prevent conflicting edits?

原因：Several units change the same page, the same model file and the same manifest.

决策 4 · Are the platform limits acceptable for this release?

原因：Some Android surfaces have no public HarmonyOS API.
